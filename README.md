# 4-DOF Robotic Arm

## Project Objective
Our goal is to design and build an autonomous robotic arm from scratch that can move a **LEGO piece** from a designated pickup spot into a cup. To keep the project simple we will first build a state management system that will allow the arm to move through a series of Waypoints. Once members have become familiar with how to move servos, we will then tackle kinematics and precise control.

## Project Setup
Since we will be using software to simulate the robotic arm, make sure you have the **Wokwi** and **PlatformIO** VS Code extensions installed. These will allow you to build and test your code using simulated hardware.
> for more information, visit the [software_reference_doc](https://docs.google.com/document/d/1s4ckiUrGYMQh16c2uRChw-FAYgOazpbwxVteR9Cr5hs/edit?usp=sharing)

## Simulator (wokwi.com)
This project utilizes wokwi's free VS Code simulator. This is so software can be developed and tested asynchronously without the need for a working arm to be built. There shouldn't be any need to change the diagram. If you encounter problems with the diagram, either let a Lead know or open an issue in this repository.
